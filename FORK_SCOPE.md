# Fork Scope

This fork is maintained for professional study and targeted contributions.

## Upstream
- https://github.com/dotnet/runtime

## Contribution Intent
- Investigate runtime internals and performance-related changes
- Reproduce issues locally before proposing fixes
- Submit focused pull requests upstream when applicable

## Local Policy
- Keep this fork as close as possible to upstream mainline
- Avoid unrelated experimental commits on default branch
- Use short-lived branches for investigation and fixes
